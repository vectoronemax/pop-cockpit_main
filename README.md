# 中国人口版图

31 省常住人口（1990–2023）与第七次全国人口普查省际流动的单页数据大屏。纯静态页面，没有后端，不向外部发送请求。

**本作品仅用于教学展示。**

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面和交互 |
| `data.js` | 聚合后的数据，全局变量 `window.POP_DATA`。由 `build_data.py` 生成，勿手改 |
| `build_data.py` | 读 `data/pop/` 下 4 个 CSV，写出 `data.js`。项目根目录运行：`python3 apps/pop-cockpit/build_data.py` |

页面只读 3 个文件：`./data.js`、`./assets/china.js`（底图）、`./assets/echarts.min.js`（图表库），见 `index.html` 末尾的 `<script src>`。页面不读 CSV。在项目根目录起本地服务（如 `python3 -m http.server 8000`）后访问 `/apps/pop-cockpit/`。

### 4. 底图

- **是什么：** DataV.GeoAtlas 的省级 GeoJSON，内联为 `assets/china.js`（`window.CHINA_GEO`），页面用 `echarts.registerMap('china', CHINA_GEO)` 注册。共 35 个要素：31 省，台湾省、香港特别行政区、澳门特别行政区，另有 1 个没有名字的要素（adcode `100000_JD`，范围 108.2°–122.8°E、3.4°–24.6°N，位置在南海，应是南海部分）。台港澳在图上画出，但没有数据，悬停显示「暂无数据」。
- **能不能公开发布：不能当作可正式公开发布的底图。**
  1. 没有审图号，也没有送审。
  2. 阿里云官方说明：「DataV.GeoAtlas工具中的数据来自高德开放平台，仅供学习和交流使用」，「如有版权相关问题，请前往高德开放平台进行确认」（[DataV GeoAtlas 地理小工具](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)，2026-11-04 读取）。课程清单里把 DataV 写作「公开」，与这句不一致，以官方为准。
- **本页怎么用：** 仅用于教学展示，页脚已写明；图上界线不作为划界依据。
- **要正式对外**（公众号、报告、展板、商用）：改用自然资源部「标准地图服务」下载的带审图号版本，或按规定送审；拿不准先问单位的测绘或宣传部门。

### 5. 页脚署名

页面页脚一行：

> 数据：国家统计局《中国人口和就业统计年鉴 2024》（1990–2023 各省常住人口；普查年为普查推算，其余年份为抽样推算）· 第七次全国人口普查（2020 省际流动）· 底图：DataV.GeoAtlas（数据来自高德开放平台）· 台湾省、香港、澳门暂无数据 · 仅用于教学展示

本页没有用 OpenStreetMap 的数据，所以不写「© OpenStreetMap contributors」。以后若加入路网、设施、地铁线路等 OSM 衍生数据（ODbL），必须补上这一句。

页面按 1920 × 1080 设计、整页等比缩放，页脚在最下方一行。手机竖屏显示的是整页缩略图，需双指放大才能读清。

## Streamlit Community Cloud 部署

入口是仓库根目录的 `stream_app.py`，依赖在 `requirements.txt`。
复用本仓库的 HTML、数据与图表库，将本地 JS 内联到 iframe，保留地图与图表交互，无需依赖 GitHub Pages 在线服务。

本地运行：

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run stream_app.py
```

部署：

1. 将 `stream_app.py`、`requirements.txt` 与更新后的 README 提交到本仓库；保留现有 `index.html`、`data.js`、`assets/`。
2. 登录 https://share.streamlit.io/ 并连接 GitHub。
3. 点击 Create app，选择 `vectoronemax/pop-cockpit_main`、分支 `main`。
4. Entrypoint file path 填 `stream_app.py`，Python 建议选择 3.11 或更新的受支持版本，然后 Deploy。
5. 发布成功后，检查地图、年份/指标切换、流动页、分型页和手机浏览。应用会获得独立的 `https://你的应用名.streamlit.app/` 地址；原仓库的 GitHub Pages 地址仍保留，新仓库无需启用 Pages 即可部署 Streamlit。

大屏区域默认高度 850px，可在“浏览设置与数据说明”中调节。手机竖屏可在大屏内滚动浏览，建议横屏查看。该入口只渲染仓库内可信 HTML/JS，不接收用户上传代码。
